# Job Application Form

A simple Job Application Form created using **HTML5 only**, with no CSS or JavaScript. It is a beginner-friendly project designed to practice HTML page structure, form elements and built-in form validation.

## About the Project
The form collects personal details, academic details, skills, preferred job role and documents from a job applicant. It uses HTML5 input types, so the browser checks required fields, email format and dates without any JavaScript.

## Technologies Used
- HTML5

## Features
- **Personal details:** name, email, date of birth, house number, street, state, city, gender and phone number
- **State dropdown:** includes the states of India
- **Academic details:** college/university name, CGPA and HSLC percentage
- **Skills:** checkboxes for HTML, CSS, JavaScript, React JS and Python
- **Role selection:** Front End, Back End, Java Full-Stack or Python Full-Stack Developer
- **Experience/Projects:** a text area to describe your work
- **File uploads:** resume and cover letter (PDF only)
- **Submit and Reset buttons**
- **Instructions section** for applicants
- Required-field validation using HTML5 attributes

## HTML Elements Used
`form`, `fieldset`, `label`, `input` (text, email, date, tel, number, radio, checkbox, file), `select`, `option`, `textarea`, `button`, `ol`, `footer`

## Purpose
The purpose of this project is to improve my HTML skills and gain practical experience in creating web pages and application forms.

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open the `index.html` file in any web browser.
